# Portfolio guide

The `/ask` page retrieves passages from the public website before asking a free text model to answer. `.generated/portfolio-rag-index.json` is generated at build time from the HTML actually rendered by Next.js: 42 sitemap pages (excluding the chat itself), eight original lab exhibits and five Anatomy figures. At this revision it holds 55 public routes and exhibits and 1,071 passages. Unlisted/noindex legacy routes, private repositories and private client records are deliberately not indexed.

`scripts/build-portfolio-rag.mjs` reads prerendered pages from `.next/server/app`, renders any dynamic sitemap route using a temporary local Next server, strips scripts/navigation/forms/SVG markup and extracts the visible page text under headings with linkable anchors. The production build runs twice: the first pass renders current pages, the indexer refreshes the corpus, and the second bundles that refreshed index into the API. `pnpm rag:refresh` rebuilds the index from an existing `.next` build for inspection; run `pnpm build` after editing site content. The generated file is ignored by Git and rebuilt from the repository's public pages at every deployment; the extraction script is the reviewable source of truth.

At request time, `lib/portfolio-rag.ts` uses a local BM25-style ranking with title/section boosts, bilingual terms and a cap of two passages per page. The API sends up to seven retrieved passages to the free model, labels labs/figures as demonstrations and returns numbered source links. If the model is absent, exhausted or returns a non-answer, the page shows source excerpts instead. This is lexical retrieval-augmented generation; it does not use a paid vector database or claim that the model has absorbed the entire site. Questions with weak lexical overlap, especially outside the bilingual synonym set, can miss a relevant passage.

Live answers require `OPENROUTER_API_KEY` as a Production Secret in Vercel. If a key has been shared in chat, rotate it in OpenRouter and replace this secret; redeploy afterward. Keep keys out of the repository, browser bundle, preview logs and client-side variables. For local work, use an ignored `.env.local`.

The server uses the fixed free text model `nvidia/nemotron-3-ultra-550b-a55b:free`. The automatic `openrouter/free` router sometimes returned a classifier label instead of a conversational answer, so it is not used here. Model availability and free quotas may change. Requests are capped by body length, conversation length, output tokens, a 30-second timeout and a best-effort per-IP and per-instance memory counter. Obvious non-answers fall back to the retrieved excerpts. **These in-memory counters are not a distributed rate limit on Vercel.** Before driving substantial public traffic to the live model, add a persistent rate limit or Vercel Firewall rule to `/api/portfolio-chat`, and monitor the OpenRouter key's usage. Do not promise unlimited free inference.

Visitor questions are processed by OpenRouter and an underlying model provider when live AI is enabled. The page does not save the conversation, sends only the most recent messages, rejects obvious email addresses and API keys, and asks visitors not to enter client or personal data. Those checks cannot guarantee that a visitor never submits sensitive information. The automated answer is labeled as such and includes server-selected links for verification.
