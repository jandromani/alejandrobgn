# Portfolio guide

The /ask page is a public, source-linked guide to the portfolio. It gives deterministic guided answers when no API key is configured or when OpenRouter is unavailable. Its facts live in `lib/portfolio-chat.ts` and must be updated alongside the public cases.

Live answers require `OPENROUTER_API_KEY` as a Production Secret in Vercel. If a key has been shared in chat, rotate it in OpenRouter and replace this secret; redeploy afterward. Keep keys out of the repository, browser bundle, preview logs and client-side variables. For local work, use an ignored `.env.local`.

The server uses the fixed free text model `nvidia/nemotron-3-ultra-550b-a55b:free`, with a short context assembled only from public portfolio facts. The automatic `openrouter/free` router sometimes returned a classifier label instead of a conversational answer, so it is not used here. Model availability and free quotas may change. Requests are capped by body length, conversation length, output tokens, a 25-second timeout and a best-effort per-IP and per-instance memory counter. Obvious non-answers fall back to the guided response. **These in-memory counters are not a distributed rate limit on Vercel.** Before driving substantial public traffic to the live model, add a persistent rate limit or Vercel Firewall rule to `/api/portfolio-chat`, and monitor the OpenRouter key's usage. Do not promise unlimited free inference.

Visitor questions are processed by OpenRouter and an underlying model provider when live AI is enabled. The page does not save the conversation, sends only the most recent messages, rejects obvious email addresses and API keys, and asks visitors not to enter client or personal data. Those checks cannot guarantee that a visitor never submits sensitive information. The automated answer is labeled as such and includes server-selected links for verification.
